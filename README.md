Información
-----------

Carpeta de proyectos relacionados con N64.



ESP32-N64Controller
-------------------  

Código para poder leer los botones y controles del mando de la N64 desde un ESP32.


BU9850-CH32V003F4P6
-------------------

En este proyecto se ha programado un CH32V003F4P6 para poder sustituir un BU9850, y guardar partidas en la PICOCART 64.


BU9850-CH32V003J4M6
-------------------

En este proyecto se ha programado un CH32V003J4M6 para poder sustituir un BU9850, y guardar partidas en la PICOCART 64.
