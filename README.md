En esta carpeta voy a ir poniendo todos los proyectos relacionados con la N64.

Actualmente los proyectos realizados son :

-  <u>ESP32-N64Controller</u> : Código para poder leer los botones y controles del mando de la N64 desde un ESP32.

-  <u>BU9850-CH32V003F4P6</u> : En este proyecto se ha programado un CH32V003F4P6 para que pueda sustituir a un BU9850, y permita guardar partidas en una PICOCART 64.
