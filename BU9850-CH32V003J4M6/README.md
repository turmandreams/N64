
Información
-----------


Proyecto para poder salvar partidas en la placa PICOCART64, la idea es poder sustituir la eeprom BU9850 y sustituirla por un CH32v003J4M6 . 

Se ha utilizado Mounriver Studio para programar el CH32v003 , el archivo "BU9850-CH32V003j4m6.zip" contiene el proyecto exportado. Se puede importar desde el entorno de desarrollo.

Es necesario conectar GND, 3V y el Pin PC2 del CH32v003 al S_DATA de la PICOCART.

La primera vez que se realiza un salvado puede fallar, ya que la flash del ch32v003 esta vacia, una vez realizado el primer "guardado" los siguientes funcionan sin problema.
